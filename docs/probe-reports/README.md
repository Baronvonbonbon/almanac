# Probe reports

Raw JSON reports exported from the [probe](../../probe/), one file per device and run, named
`<date>-<device>-<surface>.json` — for example `2026-09-15-pixel8-inapp.json` or
`2026-09-15-iphone15-gateway.json`.

Reports include the account addresses of whoever ran the probe. Run it with a test account, or
remove the addresses before committing a report.

The answers drawn from them go in [`../PROBE-REPORT.md`](../PROBE-REPORT.md).
